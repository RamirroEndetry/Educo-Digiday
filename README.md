# DigiDay EDUCO – prezentace

Interaktivní prezentace systému dotykových panelů **DigiDay EDUCO** pro školy.
Jedna statická stránka bez build kroku, stačí otevřít `index.html` nebo nasadit přes GitHub Pages.

## Obsah

- Přínosy pro žáky, rodiče a učitele
- Klikací simulace rozhraní panelu (podle demo instalace ledware-demo.cz)
- 25 modulů softwaru LEDWARE EDUCO, jazykové mutace
- Typy panelů, technické parametry, srovnání spotřeby
- Servis, dohled 24/7, náhradní díly
- Akční cenová nabídka (platná do 30. 12. 2026) s orientační kalkulačkou
- Kontakt

## Soubory

| Soubor | Účel |
| --- | --- |
| `index.html` | Samostatná stránka pro web a GitHub Pages |
| `app.html` | Tělo stránky bez HTML obálky (zdroj pro Claude Artifact) |
| `img/` | Fotografie panelů z katalogu, logo DigiDay, obrázky z demo instalace |

## Ovládání

Tlačítko **Prezentovat** přepne na celou obrazovku. Šipky nebo mezerník přepínají sekce, Esc režim ukončí.

## Zdroje

Katalog DigiDay EDUCO, Akční cenová nabídka DigiDay EDUCO, demo instalace https://ledware-demo.cz/?desk=educo, brandbook https://brandbook.digiday.cz/.
